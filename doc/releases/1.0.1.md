# FunAsrNet 1.0.1

首个 NuGet 正式版，面向已验证的固定普通话识别、中文 VITS 合成、FSMN VAD 与电话音频处理配置。

## 安装

```shell
dotnet add package FunAsrNet --version 1.0.1
dotnet add package FunAsrNet.Vulkan --version 1.0.1
```

最低运行时 .NET 10。核心包使用纯 C# 推理；可选 Vulkan 包依赖系统 Vulkan 驱动。模型、词典与音素资产单独准备，见[模型说明](https://github.com/donet-org-cn/FunAsrNet/blob/v1.0.1/doc/models.md)。

## 本版内容

- 发布核心与 Vulkan 两个独立 NuGet 包、调试符号、XML API 文档和许可证说明。
- CPU 增加特征提取、FFT、RoPE、词表扫描 SIMD、FP32 六行矩阵分块及 Q8 整数归约优化。
- GPU 增加 FP32 专用矩阵管线、分组投影、长序列注意力与矩阵向量宽子组；依据形状与设备特性选择回退。
- 支持官方固定 BF16/FP32 权重无损展开为 FP32 GGUF，并提供离线导出工具和着色器源码校验工具。
- GitHub Actions 验证构建、数值回归、标量回退和实际 NuGet 包安装，以 OIDC 短期凭据发布，并核对公开下载内容。

## 验证与性能

本机 i7-12700 / RTX 3060 的 24 秒 ASR 样本中，CPU Q8/原始权重耗时观察值减少约 4.0%/8.4%；扩大样本 GPU 复核分别减少约 7.3%/10.8%。普通桌面批次仍有反向波动，Q8 短句基本持平。全部批次、计时条件、原始数据和精度边界见[完整报告](https://github.com/donet-org-cn/FunAsrNet/blob/v1.0.1/doc/cpu-gpu-round2-20261111.md)。

CPU 默认数值检查通过 9,552,345 项，GPU 默认数值检查通过 1,453,760 项；.NET 11 正确性回归通过。320 次正式模型调用中，同一输入的文本与 token 数一致。性能测试并非广泛语料识别率评估，GPU 实测设备仅为本机 RTX 3060；托管路径保持权重精度，沿用既有 F16 KV 缓存。

本项目不是官方 FunASR SDK，不承诺通用 ONNX 或任意上游模型兼容。默认 Web 服务使用 CPU；GPU 需通过库 API 或基准入口显式启用。详见[使用文档](https://github.com/donet-org-cn/FunAsrNet/blob/v1.0.1/README.md)与[第三方说明](https://github.com/donet-org-cn/FunAsrNet/blob/v1.0.1/THIRD_PARTY_NOTICES.md)。
