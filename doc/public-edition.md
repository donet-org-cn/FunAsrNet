# 独立公开版整理与验证

整理日期：2026-10-11。项目展示名 FunASR.NET，仓库/核心程序集/命名空间 FunAsrNet，首版 1.0.0。原版本独立保留，公开版不复制原 Git 历史。

## 发布范围

保留 C# 模型推理、音频/会话、Web 示例、CLI、Vulkan 后端、数值测试、词典和第三方许可。项目路径、命名空间、友元程序集、环境变量、界面品牌、下载文件名、服务模板统一改名。默认 Web 监听 localhost；部署模板显式配置局域网监听。没有改模型精度或推理算法。

中文 README 区分默认托管 CPU、可选 Vulkan 驱动后端与隔离原生开发对照。移除个人部署地址、证书快照、旧仓库地址、回退目录及无关历史日志。模型、音频输入、二进制、凭证和私有仓库历史不发布。

## 命名与精度

核心 API 为 `FunAsrNet`，子项目为 `FunAsrNet.Server`、`.Vulkan`、`.Cli`、`.Probe`。所有调优环境变量以 `FUNASRNET_` 开头，不需要原品牌环境变量。模型原名和上游项目名保留，避免把 GGUF/ONNX 文件名改成无法核对的名称。

历史原始记录中的引擎标签、产品提交号和硬件加载器路径保持原样，用于说明当时测量的事实。具体公开证据范围与不足见 [性能文档](performance.md)。
